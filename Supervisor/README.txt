BUS MANAGEMENT SYSTEM - SUPERVISOR MODULE


FOLDER STRUCTURE
Supervisor_Module/
  index.html
  controller/   -> Empty folder reserved for future controllers
  model/        -> sampleData.js
  views/
    pages/      -> All HTML pages
    css/        -> External CSS files
    js/         -> Page scripts and shared layout



Ticket-checker assignment supports assigning, changing and unassigning trips.
Current sample data is held in JavaScript memory and resets after refresh.
No backend/database connection is included. PHP and database integration can be added later.
